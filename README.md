
# Project

Implementing research and development of image labeling software

## Deployment

To run this project run

1.Flask server
```bash
  python app.py 
  or
  python3 app.py
```

2. Reactjs
```bash
 cd image_annotator
 npm i
 npm start
```
## Features

- Upload .svs image
- Create image labels (annotation)
- Fullscreen mode
